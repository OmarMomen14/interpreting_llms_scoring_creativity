# Reproducing the Results, But not the Interpretations: Evidence for  Artifacts in Automatic Creativity Scoring with LLMs

This is the data and code for our paper "Reproducing the Results, But not the Interpretations: Evidence for  Artifacts in Automatic Creativity Scoring with LLMs" (Workshop BlackboxNLP @ EMNLP 2026).

The .bin files for the finetuned models by [DiStefano et al. (2024)](https://psycnet.apa.org/record/2024-68847-001) can be obtained from [osf.io](https://osf.io/2dqpj).
